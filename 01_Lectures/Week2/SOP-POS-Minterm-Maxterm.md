# การเขียนสมการจากตารางความจริง (SOP / POS)

<span class="material-symbols-outlined">arrow_back</span> กลับไปที่ [[Week2-MOC|MOC สัปดาห์ 2]] | ก่อนหน้า: [[Logic-Gates]]

## <span class="material-symbols-outlined">key</span> Keyword

- **Minterm** — เทอมผลคูณ (product term) ที่ตัวแปรทุกตัวปรากฏครบ ได้ผลลัพธ์ตรงกับแถวที่เอาต์พุตเป็น **1**
- **Maxterm** — เทอมผลบวก (sum term) ที่ตัวแปรทุกตัวปรากฏครบ ได้ผลลัพธ์ตรงกับแถวที่เอาต์พุตเป็น **0**
- **SOP** (Sum of Product) — ผลบวกของผลคูณ (OR ของกลุ่ม AND)
- **POS** (Product of Sum) — ผลคูณของผลบวก (AND ของกลุ่ม OR)

## <span class="material-symbols-outlined">menu_book</span> Theory (เข้าใจง่าย)

การเขียนสมการจากตารางความจริงทำได้ 2 วิธี

### 1. Min Term / Sum of Product (SOP)

พิจารณาเฉพาะแถวที่ **เอาต์พุตเป็น "1"** เท่านั้น สมการที่ได้อยู่ในรูปของการ**คูณ**ระหว่างตัวแปรภายในแต่ละเทอม แล้วนำแต่ละเทอมมา**บวก**กัน

```
F(A, B, C) = A.B + A.B.C + A.B.C.D + ...
```

#### หลักการแปลงเลขฐาน 10 → Minterm

ตัวแปรที่มีค่า **1** ให้ใช้ตัวแปรปกติ ตัวแปรที่มีค่า **0** ให้ใช้ตัวแปรแบบคอมพลีเมนต์ (มีบาร์)

| เลขฐาน 10 | A | B | C | Minterm |
|---|---|---|---|---|
| 0 | 0 | 0 | 0 | Ā B̄ C̄ |
| 1 | 0 | 0 | 1 | Ā B̄ C |
| 2 | 0 | 1 | 0 | Ā B C̄ |
| 3 | 0 | 1 | 1 | Ā B C |
| 4 | 1 | 0 | 0 | A B̄ C̄ |
| 5 | 1 | 0 | 1 | A B̄ C |
| 6 | 1 | 1 | 0 | A B C̄ |
| 7 | 1 | 1 | 1 | A B C |

เพื่อความสะดวก เขียนย่อด้วยสัญลักษณ์ Σm (ผลบวกของมินเทอม) เช่น

```
F(A,B,C) = m2 + m6 + m3 = Σm(2, 6, 3)
```

#### ตัวอย่าง: จงเขียน Canonical SOP จาก f(A,B,C) = Σm(0, 2, 4, 6)

```
f(A,B,C) = Σm(0,2,4,6) = Ā.B̄.C̄ + Ā.B.C̄ + A.B̄.C̄ + A.B.C̄
```

#### สำหรับฟังก์ชัน SOP ที่ไม่เป็น Canonical Sum

ถ้าเทอมใดขาดตัวแปร ให้คูณเทอมนั้นด้วย (A + Ā) เพื่อขยายให้ครบทุกตัวแปร แล้วกระจายออก

**ตัวอย่าง:** f(A,B,C) = Ā.C + A.B̄.C + B.C̄

```
= Ā.C(B+B̄) + A.B̄.C + B.C̄(A+Ā)
= Ā.B.C + Ā.B̄.C + A.B̄.C + A.B.C̄ + Ā.B.C̄
= m3 + m1 + m5 + m6 + m2
= Σm(1, 2, 3, 5, 6)
```

### 2. Max Term / Product of Sum (POS)

พิจารณาเฉพาะแถวที่ **เอาต์พุตเป็น "0"** เท่านั้น สมการที่ได้อยู่ในรูปของการ**บวก**ระหว่างตัวแปรภายในแต่ละเทอม แล้วนำแต่ละเทอมมา**คูณ**กัน — เรียกเทอมนี้ว่า **Maxterm**

```
F(A, B, C, D) = (A+B).(A+B+C).(A+B+C+D).(A+B+C+D)
```

#### หลักการแปลงเลขฐาน 10 → Maxterm

ตรงข้ามกับ Minterm: ตัวแปรที่มีค่า **0** ให้ใช้ตัวแปรปกติ ตัวแปรที่มีค่า **1** ให้ใช้ตัวแปรแบบคอมพลีเมนต์ (มีบาร์)

| เลขฐาน 10 | A | B | C | Minterm | Maxterm |
|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | Ā B̄ C̄ | A+B+C |
| 1 | 0 | 0 | 1 | Ā B̄ C | A+B+C̄ |
| 2 | 0 | 1 | 0 | Ā B C̄ | A+B̄+C |
| 3 | 0 | 1 | 1 | Ā B C | A+B̄+C̄ |
| 4 | 1 | 0 | 0 | A B̄ C̄ | Ā+B+C |
| 5 | 1 | 0 | 1 | A B̄ C | Ā+B+C̄ |
| 6 | 1 | 1 | 0 | A B C̄ | Ā+B̄+C |
| 7 | 1 | 1 | 1 | A B C | Ā+B̄+C̄ |

เขียนย่อด้วยสัญลักษณ์ π (ผลคูณของแมกซ์เทอม) เช่น

```
F(A,B,C) = M0.M1.M5 = πM(0, 1, 5)
```

#### ตัวอย่าง: จงเขียน Canonical POS จาก f(A,B,C) = πm(0, 2, 4, 6)

```
f(A,B,C) = πm(0,2,4,6) = (A+B+C).(A+B̄+C).(Ā+B+C).(Ā+B̄+C)
```

#### สำหรับฟังก์ชัน POS ที่ไม่เป็น Canonical Product

ถ้าเทอมใดขาดตัวแปร ให้บวกเทอมนั้นด้วย (A · Ā) เพื่อขยายให้ครบทุกตัวแปร แล้วกระจายออก

**ตัวอย่าง:** f(A,B,C) = (Ā+C)(A+B̄+C)(B+C̄)

```
= (Ā+C+B.B̄)(A+B̄+C)(B+C̄+A.Ā)
= (Ā+B+C)(Ā+B̄+C)(A+B̄+C)(A+B+C̄)(Ā+B+C̄)
= M4 + M6 + M2 + M1 + M5
= πM(1, 2, 4, 5, 6)
```

### เวนไดอะแกรม (Venn Diagram)

ใช้พิสูจน์เอกลักษณ์บูลีนด้วยภาพ:

- **NOT (Ā)** — พื้นที่นอกวงกลม A
- **AND (AB)** — พื้นที่ที่วงกลม A และ B ซ้อนทับกัน
- **OR (A+B)** — พื้นที่รวมของวงกลม A และ B ทั้งหมด

**ตัวอย่างการพิสูจน์:** A + BC = (A+B)(A+C) — วาดเวนไดอะแกรมทั้งสองข้างของสมการ แล้วเทียบพื้นที่แรเงาว่าตรงกันหรือไม่ (ผลลัพธ์: พื้นที่แรเงาตรงกันทั้งสองข้าง จึงพิสูจน์ว่าเอกลักษณ์นี้เป็นจริง — ตรงกับกฎการกระจาย/ดูดกลืนในพีชคณิตบูลีน)
