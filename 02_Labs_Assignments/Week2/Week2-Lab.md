# รายงานผลแลปสัปดาห์ 2 — Logic Gate & IC

<span class="material-symbols-outlined">arrow_back</span> กลับไปที่ [[Week2-MOC|MOC สัปดาห์ 2]]

> [!important] สถานะ
> ทำแลปทั้งหมด 6 Lab เกี่ยวกับ Logic Gate และ IC โดยทำสำเร็จแล้ว **5 Lab** (Lab 1-5) ส่วน **Lab 6 ยังไม่ได้ทำ**

## Lab 1 — NOT Gate

ใช้งาน NOT Gate เพื่อวัดค่าแรงดันไฟฟ้าที่ออกมาเป็น Output ว่าอยู่ในรูปแบบไหน (เทียบกับ Truth Table ของ [[Logic-Gates|NOT Gate]])

## Lab 2 — AND Gate และ OR Gate

ใช้งาน AND Gate และ OR Gate เพื่อตรวจสอบว่าค่า Logic ที่วัดได้จริงตรงกับ Truth Table หรือไม่ (อ้างอิง [[Logic-Gates]])

## Lab 3 — NOR Gate (Adapt เป็น NOT / OR)

ใช้งาน NOR Gate ในการต่อวงจรให้ทำหน้าที่เป็น NOT Gate และ OR Gate ปกติ เพื่อฝึก Adapt การใช้งานเมื่อมีอุปกรณ์ไม่ครบ แล้ววัดค่า Logic เทียบกับ Truth Table เดิมของแต่ละเกต

## Lab 4 — NAND Gate (Adapt เป็น NOT / AND)

ใช้งาน NAND Gate ในการต่อวงจรให้ทำหน้าที่เป็น NOT Gate และ AND Gate ปกติ เพื่อฝึก Adapt การใช้งานเมื่อมีอุปกรณ์ไม่ครบ แล้ววัดค่า Logic เทียบกับ Truth Table เดิมของแต่ละเกต

## Lab 5 — XOR Gate

ใช้งาน XOR Gate ทั้งแบบสร้างขึ้นเองจากเกตพื้นฐาน (NAND/AND/OR/NOT) และแบบใช้ไอซี XOR สำเร็จรูป แล้ววัดค่า Logic เทียบกับ Truth Table ของ [[Logic-Gates|XOR Gate]]
