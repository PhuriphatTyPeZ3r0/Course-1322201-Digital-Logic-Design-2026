## Assignment 1.5 — การลบเลขฐานสองด้วย 1's Complement และ 2's Complement (อ้างอิง [[Complements]])

> [!example] ตัวอย่างที่เฉลยไว้ในสไลด์ (หน้า 44-48) — ใช้ทบทวนวิธีทำก่อนลงมือทำโจทย์ด้านล่าง
>
> **ด้วยวิธี 1's Complement:**
> - `110110 − 100001` → หา 1's(100001)=011110 → 110110+011110=1010100 (มีตัวทด → บวก end-around carry) → 010100+1 = **10101**
> - `100001 − 110110` → หา 1's(110110)=001001 → 100001+001001=101010 (ไม่มีตัวทด → ผลลบ, หา 1's complement ของผลบวกอีกครั้ง) → 1's(101010)=010101 → คำตอบ = **−10101**
>
> **ด้วยวิธี 2's Complement:**
> - `110110 − 100001` → หา 2's(100001)=011111 → 110110+011111=1010101 (มีตัวทด → ตัดทิ้ง) → คำตอบ = **10101**
> - `100001 − 110110` → หา 2's(110110)=001010 → 100001+001010=101011 (ไม่มีตัวทด → ผลลบ, หา 2's complement ของผลบวกอีกครั้ง) → 2's(101011)=010101 → คำตอบ = **−10101**

> [!warning] จุดที่ต้องระวัง
> สไลด์หน้า 48 (ตัวอย่างที่ 2 ของ 2's Complement) พาดหัวเขียนว่า "ด้วยวิธี 1's complement" แต่ขั้นตอนคำนวณจริงเป็นวิธี **2's complement** ล้วนๆ (หา 2's(110110)=001010 ไม่ใช่ 1's(110110)=001001 อย่างในตัวอย่างหน้า 45) — เป็นจุดพิมพ์ผิดบนสไลด์ต้นฉบับ ไม่ใช่ความผิดพลาดจากการถอดสรุป

**โจทย์ (ยังไม่เฉลย):**

1. จงลบเลขฐานสองต่อไปนี้ด้วยวิธี **1's Complement**
   - (ก) 10101₂ − 1001₂
   - (ข) 101101₂ − 110110₂
2. จงลบเลขฐานสองต่อไปนี้ด้วยวิธี **2's Complement**
   - (ก) 10101₂ − 1001₂
   - (ข) 101101₂ − 110110₂
